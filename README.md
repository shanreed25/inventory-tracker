# Inventory Tracker

> Object-oriented inventory tracker using TypeScript. The tracker distinguishes between a PhysicalProduct and DigitalProduct, calculates applicable taxes, and manages inventory using modules.



Setup Your Project:

- [X] Create a new directory for the project and initialize it with npm:
    - `mkdir inventory-tracker`
    - `cd inventory-tracker`
    - `npm init -y`
- [X] Install TypeScript and other dependencies:
    - `npm install typescript @types/node --save-dev`
- [X] Create a tsconfig.json file:
    - `npx tsc --init`
